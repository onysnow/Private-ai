# Module 11 — Visual Selection and Specification

*Part of Topic Authority System — Investigative & Legal-Document Evidence Edition.*

## Use when

Choosing or designing a chart, graph, table, timeline, network, ownership chart, financial-flow diagram, map, annotated document, dashboard, or legal/investigative visual.

## Prompt

```text
OBJECTIVE
Select and specify the least complex accurate visual for the stated question. Do not draw from narrative prose when a validated data/evidence table is required.

INPUTS
Question: [ONE SENTENCE]
Audience/use: [AUDIENCE]
Legal/status label: [STATUS]
Validated evidence/data: [FILES/TABLES]
Scope/exclusions: [SCOPE]
Output medium/final size: [MEDIUM]

CONSULT FIRST
- VISUAL_STANDARDS/LEGAL_INVESTIGATIVE_VISUAL_STANDARD.md
- VISUAL_STANDARDS/VISUAL_TYPE_DECISION_MATRIX.md
- the task-specific evidence, timeline, relationship, or financial module

PROCESS
1. Validate the controlling table and identify blocking defects.
2. Select the visual by question; compare a simpler alternative.
3. Define every encoding and arrow direction.
4. Define distinct treatments for documented, corroborated, alleged, inferred, hypothesized, contested, and unknown information.
5. Assign element IDs and map each to precise evidence.
6. Specify title, scope, exclusions, legend, citations, limitations, accessible text, and data-table alternative.
7. State human/legal review gates.

OUTPUT
1. Selection decision
2. Full visual specification
3. Element-to-evidence table
4. Layout/wireframe description
5. Accessibility and print requirements
6. Acceptance checklist

Do not imply causation from sequence, guilt from association, ownership from control, or documented flow across a missing intermediary.
```

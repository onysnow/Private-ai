# Module 08 — Research Gap Analysis

*Part of Research Authority System (RAS).*

## Use when

After the currency check (Module 07), before synthesis (Module 09). This
module identifies what the search did *not* establish, so the synthesis
can disclose gaps honestly instead of quietly writing around them.

## Prompt

```text
OBJECTIVE
Identify what wasn't found and would need further searching, applying the same honesty TAS requires: "not found within a defined search" is not the same as "does not exist." Characterize each gap specifically enough that a future search could be targeted at closing it.

FRAMED QUESTION, SEARCH LOG, CLAIM-LEVEL EVIDENCE, CONSENSUS MAP, AND CURRENCY FINDINGS
[FROM MODULES 01-07]

RULES
1. For each sub-question the framed question (Module 01) required an answer for, confirm whether the search actually produced a claim addressing it. If not, that sub-question is a gap, not a silently dropped requirement.
2. Characterize each gap using the population/intervention-or-topic/comparison/outcome/setting elements it is missing, adapted from the AHRQ PICOS-based gap-characterization framework — state specifically which element (population, topic/intervention, comparison, outcome, or setting/timeframe) the available evidence does not cover, rather than a vague "more research is needed."
3. Classify why the gap exists, using four reasons adapted from the same framework: (a) insufficient or imprecise information — some evidence exists but is too thin or too imprecise to support a conclusion; (b) biased information — evidence exists but its representativeness is compromised (see Module 05's findings); (c) inconsistent results — the available evidence conflicts without a clear resolution (see Module 06); or (d) not the right information — no evidence addressing this specific population/comparison/outcome/setting combination was found at all.
4. Do not convert a gap into a negative finding. "No study meeting this search's scope was found addressing X in population Y" is the correct, complete statement. "X does not occur in population Y" or "X has been disproven for population Y" is not supported by the same search and must not be written that way.
5. Distinguish a genuine research gap (the evidence base itself doesn't address the question) from a search-scope limitation (the search could not reach evidence that may exist, e.g., a paywalled specialist database or a non-English literature named as a limitation in Module 02). State which kind each identified gap is — the first requires new research; the second requires a broader search, not new research.
6. Prioritize identified gaps by how much they would change the synthesis's conclusion or usefulness if filled — a gap in a peripheral sub-question is not equivalent to a gap in the question's central claim.
7. State the specific next search or study design that would close each central gap, where this can be stated without inventing an answer to what the gap itself leaves open.
8. Read Module 07's findings before rule 1: a sub-question whose only supporting claim rests on a source Module 07 found retracted or superseded has no current support and is a gap under rule 1 — record which source fell away and why. A retracted source does not close a gap.

OUTPUT
| Gap ID | Sub-question affected | Missing element (population / topic / comparison / outcome / setting) | Reason for gap (insufficient / biased / inconsistent / not-the-right-information) | Gap vs. search-scope-limitation | Priority (central / peripheral) | What would close it |

Gap disclosure statement: a one-paragraph plain-language summary of what the search did not establish, for direct inclusion in the synthesis (Module 09) — not held back in an internal record the reader never sees.
```

## What the trial changed in the app

- **Ollama read only the end of long prompts.** Its default window is 4096 tokens and it drops the start of a
  longer prompt, the instructions first, without an error: an earlier attempt at this trial sent 26,957 tokens and
  Ollama kept 2,050, so those results were thrown away. `app/ai/llm_client.py` now sizes the window to each request
  and refuses one the model cannot hold before any evidence is sent.
- **A refusal of the app's own making.** The first version of that fix refused a theory test whose 10,503-token
  prompt fitted an 18,432-token window; Ollama's log shows nothing was cut. The check now refuses only a prompt that
  filled the whole window; run again, that theory test staged (the row above).

## Not measured

Whether the staged answers are right: staged means they passed the app's checks, not that a reporter would keep
them. Each run was asked once. The modules that start from an accepted earlier answer (DAS options, the evidence
plan, EHS public interest) were not run. Times are for this machine, not Ony's.

## What this shows (written after the 24 Oct run; regenerating replaces only the parts above)

- **The text is the same.** Wherever both read a file, the whole text matches (1.00), OCR included,
  except the email (0.45), where the Workbench also keeps the headers as text and OpenAleph keeps
  them as the email's properties.
- **The locators are not.** The same passage gets a different locator depending on which reader
  read it: a text file is `paragraph N` in OpenAleph and `line N` in the Workbench; an OCR'd page is
  `page 1` against `page 1 (OCR)`; a Word file is one `page 1` against one `paragraph N` per
  paragraph; an email is `paragraph N` against `headers` and `body, paragraph N`. A document is read
  by one reader, so its evidence locators are consistent within it, but a document read again by
  the other reader would get different locators. Making them the same changes stored locators and
  what the screens show, so it is a decision, not done here.
- **Archives and emails are kept differently.** OpenAleph makes each file inside an archive, and an
  email's attachment, a document of its own under it. The Workbench's reader reads an archive's
  files into the archive's own pages (`letter.txt · line 1`) and does not read an email's
  attachments; it says so as an issue on the document.
- **Damaged files.** A truncated PDF is `complete` with no pages and the issue "1 of 1 page(s)
  produced no extractable text" from both readers, not `failed`. A text file named `.pdf` is read
  as text by OpenAleph and fails with the reason in the Workbench's reader.
- **Names.** OpenAleph also proposes an IBAN as a BankAccount (by design,
  `openaleph_analysis.ANALYSIS_KINDS`). The Workbench's pattern finder (the fallback) misses names
  with accents (`Société Générale`, `Müller & Söhne GmbH`) and runs a name into the next word
  across a full stop (`Meridian Holdings Ltd. Payments`).

Nothing here says the fallback can be removed: it reads what OpenAleph reads, but keeps it in a
different shape, so the audit's rule (do not delete the fallback until parity and failure tests
pass) still holds.

# Workbench recordings

Screen recordings of the running Journalism Workbench on a demo case built from public records (not a real investigation). They are used on the OnySnow Studios portfolio (onysnow/onysnow-studios, `public/work/motion/`), which also holds the MP4 versions.

| File | Shows |
| --- | --- |
| `wb-home.gif` | The case home: the question, where each stage stands, the one decision only you can make next. Pointing at a party lights it everywhere it appears. |
| `wb-check.gif` | Check, on the 1MDB demo case: every claim with its evidence and status, in a shape and a word. |
| `wb-wire.gif` | The Wire: parties drawn by how they are linked, then the shortest chain of payments between two of them. |
| `wb-act.gif` | The pipeline run live: the model's answer stopped at the citation check because it cited a record not in the packet. Nothing is saved. |

Recorded with `tools/motion` in onysnow-studios (headless Chromium against the running app).
